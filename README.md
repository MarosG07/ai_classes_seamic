# AI Introduction and Software Development

**Universitat Politècnica de València (UPV)**

## About this course

This course provides a practical introduction to the tools, technologies and workflows used by software engineers in
modern technology companies, with a particular focus on Python development and AI.

The objective is to bridge the gap between academic programming and professional software development. Rather than
focusing on programming theory, we will explore how engineers organize projects, collaborate with other developers,
maintain code quality, build applications and integrate AI into real-world solutions.

Throughout the course, we will progressively develop an **Engineering Knowledge Assistant**: an application that
processes technical documents and eventually uses Retrieval-Augmented Generation (RAG) to answer questions based on
their content.

## What we will cover

The course is organized into four complementary sessions:

| Class                                        | Main topics                                                                                                                                   |
|----------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| **Class 1 – Linux, Python tooling and Git**  | Linux fundamentals, Python environments, `uv`, `pyproject.toml`, Ruff, mypy, Makefiles, Git, GitHub and professional collaboration workflows. |
| **Class 2 – Python application development** | Python project structure, HTTP and REST APIs, FastAPI, databases, SQL, testing and debugging.                                                 |
| **Class 3 – AI and RAG applications**        | Large Language Models, embeddings, vector databases, semantic search, prompt construction and Retrieval-Augmented Generation.                 |
| **Class 4 – Docker, CI/CD and deployment**   | Containers, Docker Compose, automated testing, GitHub Actions, deployment, configuration and security fundamentals.                           |

## How we will work

The course is designed around practical exercises and a continuous project.

We will use Python throughout the course and work with Linux-based development environments (native Linux, WSL2 on
Windows or native macOS).

Our tooling will focus on freely available and open-source technologies wherever possible. We will also use GitHub for
repository hosting and collaboration, and PyCharm as our development environment.

Students will work with:

- Practical demonstrations and interactive Jupyter notebooks.
- Python projects with real code to complete.
- Git repositories, branches and pull requests.
- Automated tests and code quality tools.
- A continuous project that evolves throughout the course.
